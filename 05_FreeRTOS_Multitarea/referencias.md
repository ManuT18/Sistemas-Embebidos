# Referencias y Recursos

## Documentación Oficial

### FreeRTOS Documentation

1. **FreeRTOS Official Website**
   - URL: https://www.freertos.org/
   - Descripción: Sitio oficial con documentación completa, tutoriales y descargas

2. **FreeRTOS Reference Manual**
   - Documento: `FreeRTOS_Reference_Manual_V10.0.0.pdf`
   - Contenido: API completa, configuración y ejemplos detallados
   - Capítulos relevantes:
     - Cap. 3: Task Management
     - Cap. 5: Software Timers  
     - Cap. 7: Resource Management
     - Cap. 9: Interrupt Management

3. **FreeRTOS Kernel Developer Docs**
   - URL: https://freertos.org/features.html
   - Contenido: Características técnicas del kernel y optimizaciones

### Arduino FreeRTOS Library

   - Características: Portado específicamente para Arduino AVR

5. **Arduino FreeRTOS Examples**
   - URL: https://github.com/feilipu/Arduino_FreeRTOS_Library/tree/master/examples
   - Contenido: Ejemplos prácticos para Arduino
